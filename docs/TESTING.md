# FileGuard 1.1.1 — Протокол перевірки

Дата: 16.10.2026. Середовище: Windows 11 Pro x64 (10.0.26200),
Python 3.13.2, PySide6/Qt 6.10.3. Збірка: PyInstaller 6.22.3,
hooks 2026.8, режим onefile/windowed без UPX.

## Автоматизовані перевірки

`python -m unittest discover -s tests -q`: **83 тести, OK**.
Перевірки виконуються інтерпретатором середовища з установленими залежностями.

| Група | Перевірений результат |
| --- | --- |
| SHA-256 та JSON | Коректні хеші, порожні й вкладені файли, валідація, еталони v1/v2. |
| Порівняння | П'ять статусів, однакові розмір/дата при різному вмісті, заміна файлу папкою. |
| Недоступність | Реальне блокування файлу Windows, неповний обхід, недоступний корінь, зміна під час читання. |
| Скасування та атомарний запис | Неповні результати не замінюють завершені; попередні файли зберігаються при збої. |
| Виключення | Маски, папки, сталі параметри еталона, службові підпапки. |
| SQLite та експорт | Знімки історії, транзакції, пошкодження, кирилиця, хеші й усі рядки TXT/CSV попри фільтр. |
| Налаштування | Відновлення, зіпсований JSON, збої запису та сумісність зі старими файлами параметрів. |
| Qt | 15 послідовних фонових перевірок, позначки статусів, помилка JSON, закриття під час роботи. |
| Оформлення | Світлі кути картки налаштувань при темній системній палітрі. |
| Обсяг | Порожня папка, потім 1000 невеликих файлів та двійковий файл 16 МіБ; усі 1001 порівняно правильно. |

Наскрізний тест проходить шлях від створення еталона до відкриття історії
та TXT/CSV після переміщення джерела. Хеші й рядки CSV перевірено незалежно.

## Приймання Windows-збірки

У версії 1.1.1 повторно виконано всі 83 тести та обидві перевірки Qt вище.
Перезібраний exe запущено з іншої робочої папки: перевірено версію у вікні,
світлий фон, скруглення та сторінку налаштувань без перемикача скла.
Ефект вилучено, оскільки успіх системного API не підтверджував видимого розмиття.

Під час приймання версії 1.1.0 exe з розпакованого архіву запущено з іншої робочої папки, у шляху
з українськими символами та пробілами. Дії виконано справжніми кнопками
і системними файловими діалогами.

| Крок | Результат |
| --- | --- |
| Запуск | Працює FileGuard 1.1.0, стилі та векторні значки включено до exe. |
| Старий еталон | JSON формату v1 завантажено без зміни формату користувачем. |
| Новий еталон | Застосунок створив JSON для трьох демонстраційних файлів. |
| Зміни тестової копії | Змінено Приклад.txt, прибрано Нотатки.txt, додано Новий.txt. |
| Порівняння | Усього 4: без змін 1, змінено 1, додано 1, видалено 1, помилок 0. |
| Фільтр та CSV | Фільтр показав один змінений файл; CSV містить усі 4 записи з правильним SHA-256. |
| Еталон та SQLite | JSON не змінився, повний результат збережено в історії біля exe. |
| Перезапуск | Відновилися папка та фільтр; збережений звіт відкривається після переміщення вихідної папки. |

Під час пакування виправлено підхоплення сторонньої ICU з PATH:
скрипт використовує лише каталоги середовища й системи та включає
узгоджені бібліотеки VC Runtime із Qt. Системні DLL не змінюються.

Архів пройшов перевірку CRC та SHA-256 усіх файлів за SHA256SUMS.txt.
Він містить exe, інструкцію, початкові приклади, тексти ліцензій і порожні
data/reports. Локальна історія, налаштування та тестові еталони не включені.
Актуальна сума ZIP виводиться скриптом збирання; після повторного збирання
вона може відрізнятися.

## Межі перевірки

Перевірено цей комп'ютер із Windows 11 x64. Окремий чистий комп'ютер
без Python, інші версії Windows, ARM, мережеві диски та всі варіанти DPI
не перевірено.

SHA-256 не замінює довіру до еталона, антивірус або резервну копію.
Сканування всієї папки не є миттєвим атомарним знімком.
