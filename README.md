# FileGuard — Контроль цілісності файлів

Курсовий проєкт з дисципліни «Безпека та захист програм і даних».

## Поточний стан: етап 1

Реалізовано головне вікно, вибір і перевірку шляху до папки, вкладки
«Перевірка», «Історія», «Налаштування», таблицю та порожній стан результатів.
Параметр включення вкладених папок синхронізовано між вкладками.

Створення/завантаження еталона, хешування, порівняння, збереження історії та
експорт ще не реалізовано. Відповідні елементи неактивні. Лічильники показують
тире, оскільки перевірку ще не виконували. Поточні налаштування зберігаються
лише протягом одного запуску.

## Запуск у Visual Studio Code

Потрібен Python 3.10 або новіший із tkinter. Зовнішні пакети не потрібні.
Перевірено на Windows із Python 3.13.2 та Tk 8.6.

1. Відкрити у VS Code папку `FileGuard`, у якій міститься `main.py`.
2. Відкрити термінал через меню **Terminal → New Terminal**.
3. Виконати:

```powershell
python main.py
```

Можна запускати `main.py` з іншої робочої папки, указавши повний шлях.
Якщо команда `python` недоступна, спробувати `py -3 main.py`.

## Архітектура: MVC та сервіси

```text
main.py                         Створення та поєднання компонентів
app/models.py                   Стан застосунку без залежності від tkinter
app/controllers/app_controller.py Оброблення дій, оновлення стану
app/views/main_window.py        Вікно, віджети, системні діалоги
app/services/directory_service.py Перевірка папки у файловій системі
data/                           Місце для майбутніх еталонів і налаштувань
reports/                        Місце для майбутніх звітів
demo_files/                     Безпечні приклади для демонстрації
tests/                          Перевірки поведінки контролера та сервісу
```

Напрямок взаємодії: **дія у View → Controller → Service → Model → оновлення View**.
Контролер залежить від контракту `AppView`, тому його можна перевіряти без вікна.
Сервіс не імпортує tkinter. Представлення не працює з файлами перевірки напряму.
Коментарі та пояснювальні рядки документації в коді написано українською.

## Контроль версій

Репозиторій: [Vadimaooo/FileGuard](https://github.com/Vadimaooo/FileGuard).
Основна гілка: `main`.

Після завершення кожного етапу:

1. Перевірити програму та актуальність цієї інструкції.
2. Переглянути зміни через `git diff` і перелік файлів через `git status`.
3. Зберегти завершені зміни окремим комітом із коротким описом українською.
4. Надіслати коміт до GitHub командою `git push`.

Еталони, звіти, локальні налаштування редактора та службові файли Python
не включаються до репозиторію. Для відтворення структури папок `data/` і
`reports/` зберігаються лише порожні файли `.gitkeep`.

## Як перевірити перший етап

1. Запустити застосунок і перевірити відображення трьох вкладок.
2. Натиснути «Обрати папку» та вибрати `demo_files` або іншу папку.
3. Переконатися, що шлях відображається у полі та змінюється повідомлення стану.
4. Повторно відкрити діалог і скасувати вибір: попередній шлях має зберегтися.
5. Змінити прапорець вкладених папок і перевірити його на вкладці налаштувань.
6. Змінити розмір вікна: таблиця повинна розтягуватися разом із ним.
7. Переконатися, що таблиця порожня, а кнопки майбутніх операцій неактивні.

Автоматизовані перевірки основи:

```powershell
python -m unittest discover -s tests -v
```

Перевірка створення справжнього вікна потребує графічного сеансу Windows:

```powershell
python tests/smoke_ui.py
```
