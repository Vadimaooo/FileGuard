# Як побудований інтерфейс FileGuard 1.1

Мова програми залишається Python. PySide6 надає доступ до Qt — бібліотеки
графічних елементів. Для інтерфейсу використано Qt Widgets.

## Чотири основні поняття

1. **Віджет** — елемент інтерфейсу: `QPushButton` є кнопкою,
   `QLabel` показує текст, `QTableView` показує таблицю.
2. **Компонування** — правило розміщення елементів. `QVBoxLayout`
   розташовує їх вертикально, `QHBoxLayout` — горизонтально. Компонування
   пристосовуються до зміни розміру вікна.
3. **Сигнал** — повідомлення про дію. Наприклад, кнопка надсилає `clicked`.
4. **Обробник** — функція, підключена до сигналу через `connect`.
   Вона передає команду контролеру.

Приклад із головного вікна:

```python
self.check_button = self.button(
    "Перевірити цілісність",
    lambda: self._controller.check_integrity(),
    True,
)
```

Допоміжний метод `button` створює `QPushButton` і підключає її `clicked`
до переданої функції. Прапорець `True` обирає стиль головної синьої кнопки.

## Архітектура MVC

- `app/models.py` зберігає параметри, еталон і результати у класах даних Python.
- `AppController` отримує команди й запускає сервіси у фоновому потоці.
- `MainWindow` відображає модель і відкриває діалоги. Файли для перевірки
  вона самостійно не читає.
- Сервіси SHA-256, JSON, SQLite та експорту працюють незалежно від Qt.

Потік взаємодії: натискання → контролер → сервіс → результат у моделі →
`render_state` головного вікна.

`QTimer` викликає опитування завершення операції в головному потоці.
Робочий потік передає результат через чергу Python і не звертається до віджетів.
При відновленні параметрів `QSignalBlocker` тимчасово блокує сигнали:
програмна зміна перемикача не повинна викликати нову команду користувача.

## Розподіл файлів

| Файл | Відповідальність |
| --- | --- |
| main_window.py | Сторінки, кнопки, синхронізація стану й діалоги. |
| theme.qss | Кольори, відступи, скруглення та вигляд різних станів. |
| widgets.py | Перемикач, картка, переміщення та зміна розміру вікна. |
| icons.py | Векторні значки, які малюються з SVG. |
| table_models.py | Читання знімків для таблиці та малювання кольорових позначок. |
| saved_result_window.py | Перегляд повного збереженого результату. |
| windows_effects.py | Необов'язковий системний фон Windows. |

`ResultsModel` є адаптером між завершеним результатом і `QTableView`.
Він не обчислює хеші й не замінює модель MVC. Qt запитує дані для рядків,
які потрібно намалювати; окрема кнопка чи мітка для кожного файлу не створюється.
`StatusDelegate` малює маленьку округлену позначку статусу.

Скло — додаткове оформлення. Якщо системний API відсутній або відмовляє,
застосунок продовжує працювати зі звичайним світлим фоном.
