# FileGuard 1.0 — Протокол перевірки

Дата: 16.10.2026. Середовище: Windows 11 Pro x64 (10.0.26200),
Python 3.13.2, Tk 8.6. Збірка: PyInstaller 6.12.0, hooks 2025.2,
режим onefile/windowed без UPX.

## Автоматизовані перевірки

Команда `python -m unittest discover -s tests -q`: **78 тестів, OK**.
У контрольному запуску набір виконався за 3,394 с; це тривалість тестового
набору на цьому комп'ютері, а не гарантія швидкості сканування.

| Група | Перевірений результат |
| --- | --- |
| Вибір папки та MVC | Неправильний шлях не змінює поточний стан; контролер перевіряється без tkinter. |
| SHA-256 та JSON | Порожні/вкладені/двійкові файли, коректні хеші, валідація структури й сумісність еталонів v1/v2. |
| Порівняння | П'ять статусів, однакові розмір/дата при різному вмісті, заміна файлу папкою та видалення. |
| Недоступність | Реальне блокування файлу Windows, неповний обхід, недоступна коренева папка, зміна під час читання. |
| Скасування та запис | Попередні завершені результати зберігаються; атомарна заміна не псує старі файли при збої. |
| Виключення | Маски, папки, відносні шляхи, незмінність правил завантаженого еталона, службові підпапки. |
| SQLite | Відновлення повного результату, транзакції, скасування, пошкодження й відмова сховища. |
| TXT/CSV | Кирилиця, хеші, всі рядки незалежно від фільтра, порожній результат, захист текстових формул. |
| Налаштування | Повторний запуск, розмір вікна, пошкоджений JSON, закриття під час роботи та помилка запису. |
| Шляхи exe | Дані біля виконуваного файлу, незалежність від робочої папки та тимчасових ресурсів. |

Додаткові наскрізні тести знаходяться у `tests/test_acceptance.py`:

1. Створення еталона → зміна/додавання/видалення → перевірка → історія та
   налаштування → переміщення вихідної папки → відкриття історії → TXT/CSV.
   Незалежно звірено SHA-256, підсумки та рядки CSV; початковий JSON не змінено.
2. Порожня папка, потім 1000 невеликих файлів і один двійковий файл 16 МіБ.
   Після збереження/завантаження еталона всі 1001 файл отримали «Без змін»;
   кінцеві показники прогресу відповідають кількості й сумі прочитаних байтів.
3. Справжній пошкоджений файл SQLite: успішний результат залишився у моделі,
   вихідний файл не змінено, користувач отримує повідомлення про збій історії.

## Справжні вікна tkinter

Обидві команди завершилися успішно:

```powershell
python tests/smoke_ui.py
python tests/smoke_persistence_ui.py
```

Перевірено кнопки створення/завантаження/порівняння, картки, кольори,
відомості, фільтр із порожнім результатом, помилки, експорт, розмір вікна
та порційне заповнення таблиці 1200 рядками. Другий сценарій відкрив
збережену перевірку у новому вікні після перезапуску, відновив параметри
й експортував історичний результат, коли початкової папки вже не було.

## Приймання готового exe

Перевірявся exe з розпакованого `FileGuard-Windows.zip`, запущений з іншої
робочої папки. Дії виконано через справжні кнопки та системні файлові діалоги.

| Крок | Фактичний результат |
| --- | --- |
| Запуск | Відкрилося вікно FileGuard 1.0.0 без консольного вікна. |
| Створення еталона | Exe самостійно створив JSON для трьох демонстраційних файлів. |
| Контрольовані зміни тестової копії | Змінено Приклад.txt, прибрано Нотатки.txt, додано Новий.txt. |
| Перевірка | Усього 4: без змін 1, змінено 1, додано 1, видалено 1, помилок 0. |
| Фільтр | «Змінено» показав один файл; загальні картки залишилися для всіх чотирьох. |
| CSV через системний діалог | 4 рядки попри фільтр; статуси й хеш зміненого файлу незалежно перевірено через csv/hashlib. |
| Еталон після перевірки | SHA-256 самого JSON залишився незмінним. |
| Історія | SQLite біля exe містить повний результат із тими самими лічильниками. |
| Закриття і запуск знову | Остання папка та фільтр відновилися з settings.json біля exe. |
| Вихідну папку переміщено | Після повторного запуску історія відкрила повний збережений результат без читання вихідних файлів. |

## Пакування

Архів пройшов перевірку CRC (`ZipFile.testzip`). Після розпакування всі
файли звірено з `SHA256SUMS.txt`. Архів містить лише exe, інструкцію,
три початкові демонстраційні файли, контрольні суми та порожні data/reports.
Особисті еталони, налаштування, історія й тестові звіти до архіву не включені.

- Розмір FileGuard.exe: 12 585 595 байтів.
- Розмір FileGuard-Windows.zip: 12 358 363 байти.
- SHA-256 ZIP: `62bcf8680e798b8031fb90d63d35f1920c1cbe10414d4c8619fc594d48fe42c2`.

Після повторного збирання розмір і контрольна сума можуть відрізнятися.
Скрипт збирання виводить актуальну суму ZIP.

## Межі перевірки

Готовий exe перевірено на цьому комп'ютері з Windows 11 x64; запуск
на окремій чистій машині без установленого Python не перевірявся.
Інші версії Windows, ARM, мережеві диски та всі комбінації DPI не перевірено.
Робота без Python забезпечується включенням інтерпретатора та бібліотек
до збірки, але окремий комп'ютер потребує власної приймальної перевірки.

Програма не є антивірусом, не підписує еталон і не робить атомарний знімок
усієї файлової системи. Практичні обмеження наведено в інструкції користувача.
